## Setup on the new machine

1. **R 4.6.x.** This project was built on R 4.6.1, arm64 macOS.
2. **Point at the data**, if the 5.1 release lives somewhere other than the
   Dropbox path. Add to `~/.Renviron`:
   ```
   ABCD_REL=/path/to/abcd-data-release-5.1/core
   ```
3. **Install packages** from the project folder:
   ```
   Rscript 00_install.R
   ```
   This installs the CRAN packages, plus kml 2.5.0, longitudinalData 2.4.7 and
   clv 0.3-2.5 from the CRAN archive, with two small patches (see the README,
   "Package notes"). rgl is built without OpenGL. Platform notes:
   - **macOS:** needs the Xcode command-line tools (for compiling).
   - **Linux:** needs `build-essential`; rgl's `--disable-opengl` build works the same way.
   - **Windows:** needs Rtools 4.6 to compile clv and kml from source.
   Exact versions are in `output/logs/package_versions.txt`.
4. **Check the setup.** `Rscript 01_data.R` should reproduce the sample flow in
   `output/logs/sample_flow.txt` (10,088 / 9,003 / 8,331), but only if the raw
   tables were copied. Otherwise, check that `readRDS("data_derived/wide.rds")`
   has 10,088 rows.

## Running long jobs

- `03_run.R` (and the stability runner, once built) skips finished tasks and saves
  each one in a single step, so after a crash just rerun the same command.
- Cores are the second argument (`Rscript 03_run.R full 12`). On a machine with
  more cores, use cores − 2 to leave some headroom.
- **Keep the machine awake.**
  - macOS: run under `caffeinate -i`, keep it plugged in and keep the lid open.
    A closed lid pauses the run even with caffeinate (this cost about 2 hours on
    2026-10-23).
  - Linux: use `systemd-inhibit` or `nohup` on a machine that doesn't suspend.
- Runtimes on the full sample (12 cores, M-series Mac): GMM 75-265 min per task,
  GBTM about 25 min, everything else seconds to minutes.

## Known gotchas

- One child has no `interview_age` at any wave. `01_data.R` fills their ages with
  the median at each wave, after imputation, so nothing else changes.
- mclust masks `purrr::map`. Use `purrr::map` explicitly in any code that loads mclust.
- latrend's GBTM wrapper ignores gridsearch, so GBTM is fitted through
  `lcMethodLcmmGMM(random = ~ -1)`.
- Seeds must be integers for latrend.
